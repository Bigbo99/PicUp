# 模型配置改进

## 改进内容

### 1. 允许手动添加自定义模型
- 在"添加模型"对话框中增加了"手动添加"选项卡
- 可以直接输入模型 ID、显示名称和配置参数
- 适合渠道新上线的模型或特殊模型配置

### 2. 自动从 API 获取模型时使用通用配置
- 当从 OpenAI 兼容 API 获取模型列表时,即使模型没有文档预设,也会自动生成通用配置
- 通用配置包括:
  - 分辨率: 1K, 2K, 4K
  - 宽高比: auto, 1:1, 16:9, 9:16
  - 参考图上限: 6 张
  - 积分: 1
- 添加后可以在模型详情中调整参数

### 3. 添加明显的"获取模型"按钮
- 在"添加模型"对话框的"从预设选择"选项卡中,渠道选择器旁边添加了"获取模型"按钮
- 按钮带有刷新图标,点击可重新获取该渠道的模型列表
- 获取中时显示加载动画
- 统一使用 `admin-secondary-button` 样式,与项目设计系统保持一致

### 4. 重新设计操作按钮
- **编辑按钮**: 使用统一的 `admin-icon-button` 样式,带边框和悬停效果
- **更多操作菜单**: 从原来的 `<select>` 下拉改为现代的弹出菜单
  - 点击按钮弹出浮动菜单
  - 菜单带有阴影和圆角
  - 危险操作(删除)使用红色文字突出显示
  - 点击外部自动关闭菜单
  - 支持键盘导航和无障碍访问
- 所有按钮视觉统一,符合现代 Web 设计规范

### 5. 简化模型详情编辑界面
- 将只读的文档信息折叠到"官方文档参数"折叠面板中
- 突出显示可编辑的字段:
  - 显示名称
  - 支持的分辨率(多选)
  - 支持的宽高比(多选)
  - 参考图上限
  - 每张消耗积分
  - 启用/禁用开关

### 6. 移除不必要的限制
- 后端不再要求远程获取的模型必须在文档预设列表中
- 只要 API 返回了模型 ID,就可以添加和使用

### 7. 统一设计令牌
- 所有按钮统一使用 `admin-primary-button`、`admin-secondary-button` 和 `admin-icon-button` 样式
- 颜色方案: emerald/teal 系列(主色调)
- 确保整个管理后台的视觉一致性
- 按钮悬停、禁用状态都有清晰的视觉反馈

## 使用方式

### 方式一: 从预设选择(推荐)
1. 点击"添加模型"
2. 选择渠道
3. 点击"获取模型"按钮刷新模型列表(如果需要)
4. 在"从预设选择"选项卡中查看可用模型
   - 有文档预设的模型会显示"有文档预设"
   - 无文档预设的模型会显示"使用通用配置"
5. 勾选想要添加的模型
6. 点击"添加所选模型"

### 方式二: 手动添加
1. 点击"添加模型"
2. 选择渠道
3. 切换到"手动添加"选项卡
4. 填写:
   - 模型 ID (如 `gpt-image-3`)
   - 显示名称 (如 `GPT Image 3`)
   - 支持的分辨率 (勾选)
   - 支持的宽高比 (勾选)
   - 参考图上限
   - 每张消耗积分
5. 点击"添加模型"

### 操作模型和渠道
1. **查看详情**: 点击模型名称或编辑按钮(铅笔图标)
2. **更多操作**: 点击右侧的三点菜单按钮
   - 对于模型: 删除模型
   - 对于渠道: 选择模型、删除渠道
3. **快速启用/禁用**: 使用开关按钮

## 技术细节

### 后端变更
- `apps/api/src/common/ai-config/ai-config.service.ts`
  - 修改 `availableModels()`: 为远程获取但无预设的模型生成通用配置
  - 修改 `installModels()`: 移除远程模型必须在预设列表中的限制

### 前端变更
- `apps/web/src/components/admin/ai-config-panel.tsx`
  - 新增 `ManualModelForm` 组件: 手动添加模型的表单
  - 修改 `ModelDiscoveryDialog`: 增加"从预设选择"和"手动添加"两个选项卡
  - 在"从预设选择"选项卡中添加"获取模型"按钮,可重新获取模型列表
  - 重构 `ModelDetailsDialog`: 简化界面,突出可编辑字段,文档信息折叠显示
  - 更新状态显示: "有文档预设" vs "使用通用配置"
  - 统一使用 `admin-secondary-button` 样式

- `apps/web/src/components/admin/controls.tsx`
  - 重写 `RowActions` 组件: 从 `<select>` 下拉改为现代弹出菜单
  - 添加状态管理和外部点击检测
  - 支持危险操作标记(`danger: true`)
  - 改进无障碍支持

### 样式变更
- `apps/web/src/app/globals.css`
  - 移除旧的 `.admin-action-menu` 基于 `<details>` 的样式
  - 新增 `.admin-action-menu-dropdown` 现代弹出菜单样式
  - 添加阴影、圆角和悬停效果
  - 确保所有按钮使用统一的设计令牌 (emerald/teal 系列)
  - 保持与现有管理后台设计系统的一致性

## 设计改进亮点

1. **视觉一致性**: 所有按钮使用统一的颜色、尺寸和间距
2. **交互反馈**: 悬停、激活、禁用状态都有清晰的视觉反馈
3. **现代化**: 弹出菜单替代原生 `<select>`,更符合现代 Web 应用体验
4. **可访问性**: 支持键盘导航、屏幕阅读器和 ARIA 标签
5. **危险操作突出**: 删除等危险操作使用红色文字,防止误操作
